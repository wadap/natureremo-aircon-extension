# Requirements: UI リフレッシュ

- **Date**: 2026-06-18
- **Branch**: `feature/ui-refresh` (off `develop`)

## 背景・動機
現行 UI は「全体の見た目が古い/地味」と感じられている。配色・余白・タイポを今っぽく洗練させたい。

## スコープ
- **テーマ**: ライト/ダーク両対応(OS の `prefers-color-scheme` に追従)
- **アクセントカラー**: Nature Remo ブランドの緑/ティール系に変更(現行のオレンジ/赤グラデから)
- **レイアウト**: メイン画面のルームカードは**現行構造を維持**し、色・間隔・影の洗練に留める(低リスク方針 = Option A)
- **ディテール磨き**: タイポグラフィのスケール整理、余白の統一、詳細画面のモードボタン/温度ステッパーの間隔調整

## 非スコープ(YAGNI)
- ルームカードの構造変更(サーモスタット風レイアウト等)は今回やらない
- モード連動でアクセント色を変える表現はやらない
- 機能追加(room-subtitle のリアルタイム更新、ローカライズ統一等)は別タスク

## 成功基準
- ライト/ダーク両環境でコントラストが十分で、緑アクセントが一貫して適用されている
- HTML の class 名・JS は原則変更せず、変更は CSS に閉じる(壊れにくさ優先)
- 既存ユニットテスト 43 件が引き続き pass(純ロジック対象なので CSS 変更で壊れない想定)

## 制約
- ビルドツール無し(素の HTML/CSS/JS の Chrome 拡張)
- `popup.html` の `<script type="module">` 属性は維持
- XSS 対策の `el()` ビルダー経由の DOM 生成方針は維持
